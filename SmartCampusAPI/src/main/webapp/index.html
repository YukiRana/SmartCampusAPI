SmartCampusAPI

Jakarta REST coursework API for rooms, sensors, and readings. The service runs on Tomcat with Jersey at /api/v1.

  • GET /api/v1 discovery metadata
  • GET /api/v1/rooms and POST /api/v1/rooms
  • GET /api/v1/sensors?type=... and nested readings

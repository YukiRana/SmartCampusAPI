SmartCampusAPI

IoT coursework API for room, sensor, and reading management. Developed by Yuki Ranathilaka. The REST base path is /api/v1.

Tomcat 10.1+ Jersey 3.x Hibernate + H2 Java 17
Discovery
GET /api/v1 returns metadata, contact info, and resource links.
Rooms
GET /api/v1/rooms, POST /api/v1/rooms, GET /api/v1/rooms/{id}, DELETE /api/v1/rooms/{id}
Sensors
GET /api/v1/sensors?type=..., POST /api/v1/sensors, GET /api/v1/sensors/{id}
Readings
GET /api/v1/sensors/{id}/readings, POST /api/v1/sensors/{id}/readings

Diagnostic hooks for rubric checks: ?trigger=forbidden and ?trigger=boom on /api/v1.

Deploy the WAR to Tomcat, then use the discovery endpoint to navigate the API.

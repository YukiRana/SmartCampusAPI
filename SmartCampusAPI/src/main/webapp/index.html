📶 Smart Campus API

RESTful JAX-RS API for campus room, sensor and reading management.
Author: Yuki Ranathilaka — 5COSC022W Client-Server Architectures 2025/26

Jersey 3.1.6 Tomcat 10.1+ Java 17 In-Memory (ConcurrentHashMap) JAX-RS / Jakarta EE

Base URL

http://localhost:8080/SmartCampusAPI/api/v1

Discovery

GET /api/v1 — API metadata, contact, and HATEOAS resource links

Rooms — /api/v1/rooms

GET /api/v1/rooms — List all rooms
POST /api/v1/rooms — Create a room (201 + Location)
GET /api/v1/rooms/{roomId} — Get room by ID
DELETE /api/v1/rooms/{roomId} — Delete room (409 if sensors exist)

Sensors — /api/v1/sensors

GET /api/v1/sensors — List all sensors
GET /api/v1/sensors?type=CO2 — Filter by type (case-insensitive)
POST /api/v1/sensors — Register sensor (422 if roomId invalid)
GET /api/v1/sensors/{sensorId} — Get sensor by ID

Readings (Sub-Resource) — /api/v1/sensors/{sensorId}/readings

GET /api/v1/sensors/{sensorId}/readings — Reading history
POST /api/v1/sensors/{sensorId}/readings — Add reading (403 if MAINTENANCE)

Error Codes

400 Bad Request — Missing required fields
403 Forbidden — SensorUnavailableException (MAINTENANCE sensor)
404 Not Found — Room or sensor does not exist
409 Conflict — RoomNotEmptyException (delete room with sensors)
422 Unprocessable Entity — LinkedResourceNotFoundException (bad roomId)
500 Internal Server Error — GlobalExceptionMapper catch-all (no stack trace)
